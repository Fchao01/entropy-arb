# 本次运行交易统计

网页 DEX 套利页新增交易统计表，按任务展示本次进程运行的实际成交。正常停止后保留最后一份状态；下一次启动新进程会从零重新统计。旧版状态没有统计字段时显示 `—`，不从不完整历史猜测。

- 开仓次数：主腿实际增加仓位且两腿有匹配成交的批次，包含加仓。未成交挂单、撤单和平仓不计数。
- 主腿、对冲腿和合计成交额：已确认成交数量乘实际平均成交价，包含开仓、平仓和后续补对冲。合计是两腿成交额之和。
- 手续费：按 YAML 中对应 maker/taker 费率和成交额计算；交易所回报未提供实际收取费时不能称为账单核实值，不含资金费。
- 价差损益：各交易所分别 FIFO 匹配本次运行的开平仓成交，计算已实现的价格损益。开仓时两腿的现金价差不是已实现利润。
- 净损益：价差损益减去本次所有成交手续费。开仓手续费立即扣除，因此仅开仓、未平仓时已实现净损益可能为负。
- 未平仓浮盈：未匹配本次成交按当前中间价计算，单列，不加入已实现净损益。
- 每万美元净磨损：`−净损益 / 双腿合计成交额 × 10000`，单位美元。正数为成本，负数为盈利；没有成交额时显示 `—`。

启动前旧仓缺少成本、成交价格或最终结果未确认、仓位被外部操作改变时，对应损益显示 `—`。这些统计不包含资金费、资金划转和手动交易，与账户权益变化口径不同；MTM 会话估值仍在监控中独立展示。
